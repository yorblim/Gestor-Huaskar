# Política de Seguridad 🛡️

La seguridad de Gestor Huaskar y de los datos de sus usuarios es una prioridad absoluta.

---

## 📦 Versiones Soportadas

Actualmente se proporciona soporte de seguridad y parches en las siguientes versiones:

| Versión | Soportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🚨 Reporte de Vulnerabilidades

Si descubres una vulnerabilidad de seguridad en este proyecto:

1. **NO abras un issue público.**
2. Envía un correo electrónico detallado a los mantenedores del proyecto o utiliza la pestaña **Security > Report a vulnerability** en GitHub.
3. Incluye:
   - Descripción detallada de la vulnerabilidad.
   - Pasos para reproducir el problema o prueba de concepto (PoC).
   - Componente o ruta afectada.
   - Impacto potencial estimado.

Nos comprometemos a acusar recibo dentro de las primeras 48 horas y a trabajar diligentemente en una solución o parche antes de cualquier divulgación pública.
